About FoodExpress

Food Delivery Management System

A comprehensive food delivery platform built as a college project using Python, Flask, MySQL, HTML, CSS, and JavaScript.

Features

  • Customer registration, login, and order tracking
  • Restaurant menu management
  • Delivery agent assignment and tracking
  • Admin dashboard with reports and charts
  • Automatic 10% discount on orders above ₹500
  • Real-time order status updates

Technology Stack

  • Backend: Python + Flask
  • Database: MySQL
  • Frontend: HTML5, CSS3, JavaScript
